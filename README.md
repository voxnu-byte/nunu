# NUNU — portfolio

Obidjonov Nurmuhammad (Nunu) shaxsiy portfolio sayti: voxel togʻlar (Three.js), montaj uslubidagi perehodlar (GSAP), pixel ikonkalar.

## Ishga tushirish
```bash
npm install
npm run dev
```

## Tahrirlash
- Matnlar, havolalar, showreel: `src/config.ts`
- Pixel ikonkalar va personajlar: `src/lib/pixel.tsx`
- Brend ikonkalar: `src/lib/icons.tsx`

## Deploy
